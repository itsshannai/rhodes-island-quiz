# 罗德岛入职档案

《明日方舟》非官方同人测试。24 道日常情境题，20 位干员。答题数据仅在浏览器内计算。

通过 GitHub Pages 试玩，或下载整个仓库后打开 `index.html`。

## 匹配规则

每四题对应一个性格维度。每题给出四种反应，映射为 −3、−1、1 和 3。计算六维平均分后，与干员档案的手工设定做欧氏距离比较。匹配指数为 100 ×（1 − 距离 ÷ 理论最大距离）。相同距离为并列，主卡由英文代号打破并列。角色分值为娱乐向解读。
